25. Background Tasks

Sidebar gear Settings Tasks tab (Admin or Access Task Manager permission)

The Task Manager is the Settings → Tasks parent tab. The topbar bell’s Tasks view is a live status surface, not the scheduling page. A clickable topbar directory-tagging status can take an authorized user to Settings → Tasks.

TaskWhat It Does
Refresh MetadataRuns the full library reconcile path: re-reads embedded metadata, detects removed, restored, or disallowed files, and imports new files. This is distinct from a manual provider metadata fetch.
Update Book RecommendationsRebuilds personalized recommendations from books in the library.
Cleanup Deleted BooksPermanently removes database entries for books previously deleted from libraries.
Sync Library FilesUses the additive scan path to discover and import new files without performing the full reconcile cleanup.
Directory TaggingApplies or backfills directory-based tags after imports.
Bookdrop Periodic ScanningScans the configured BookDrop ingest folder and queues new files for processing.
Cleanup Temporary MetadataRemoves temporary metadata files from BookDrop and manual review workflows.
Push Metadata to FilesWrites pending database metadata back to enabled original-file formats; available only in LOCAL storage mode.
Scan Marked AI Search EmbeddingsExtracts text and generates embeddings for books marked for AI Search.
Good to Know: The table reflects the actual Task Manager task types. Manual provider metadata fetch and ISBN Discovery use background-task infrastructure but are intentionally hidden from the general task list. KEPUB conversion is not a Task Manager task type.

Scheduling and Server Time

  • Only task cards marked as schedule-capable expose cron controls. Use exactly six fields: Second Minute Hour Day-of-Month Month Day-of-Week.
  • Schedules run in the Fable server/JVM timezone, not the browser’s timezone. Check the deployment timezone before scheduling overnight work or daylight-saving transitions.
  • Save a valid expression, enable its schedule toggle, and choose whether scheduled failures should create a durable notification. A cron expression can be stored while its schedule remains disabled.

Task Notifications & the Bell

Topbar Notification Bell (see also Section 4)

Background work uses the same topbar bell described in Section 4. Quick reminder of how Tasks settings interact with it:

  • Bell → Tasks — Live progress for metadata jobs, AI Search scans, BookDrop pending files, and system jobs while they are running
  • Notifications tab — Durable WARN/ERROR failure inbox only (not success chatter). Failures persist across restarts until you dismiss them (dismiss deletes the stored row so a reload does not bring them back)
  • Error notifications toggle (per scheduled task) — When on, scheduled task failures appear in the Notifications inbox. Successful runs are recorded under Recent runs only
  • Recent runs — Expand this on a task card in Settings → Tasks for the detailed history of scheduled and manual runs with status and messages
  • Zero-item suppression — If a scheduled task completes but found nothing to do, Fable usually suppresses a bell entry so you only see actionable results
  • Dismiss on a Tasks-tab metadata card — Hides that task notification without discarding Staging review proposals; the hide survives browser reload while the task still exists
  • Clear All on the Tasks tab — Appears when finished task cards are present; dismisses all completed/error/cancelled metadata cards (and finished AI Search batch cards) in one click without cancelling work still in progress
  • Dismiss All — Clears the failure inbox from the Notifications tab. Clearing on one device syncs to other open sessions for the same account

What You Can Do

  • Run tasks manually — Start any task on demand
  • Schedule tasks — Set up automatic timing, including an Error notifications toggle so scheduled failures appear in the bell inbox
  • Cancel running tasks. Cancellation is cooperative: Fable records a cancellation request immediately, but the current provider call, file write, or book step may finish before the next cancellation checkpoint stops the task.
  • View task history and results — Expand Recent runs on a task card to see the last scheduled and manual runs with status and messages
  • Use Library Settings to change library naming and scan options without touching directories
  • Use Manage Directories to add or remove library paths with explicit directory-focused actions
  • Use Save & Scan New Directories when you want Fable to import only from the directories you just added instead of rescanning the entire library
  • Use Scan for New Files for safe additive discovery without a full reconcile
  • The library maintenance dialog requires explicit acknowledgement before running Reconcile Library to prevent accidental full-scans
  • Scheduled Library Scan jobs use the same safe additive discovery path as the manual Scan for New Files action
  • Use Library Maintenance when you intentionally want to reconcile a library or run library-wide sidecar rewrite/import tools
  • Monitor long-running directory-tagging follow-up work after imports, including the live status message and estimated time remaining when enough progress has been measured; additive scans limit that follow-up to newly imported books, while manual reconcile can still tag the whole library
  • Directory-tag rule changes affect future imports only; existing book tags are not retroactively modified

Cancellation and Restart Boundaries

  • A cancelled run remains in Recent runs as CANCELLED; it is not erased and does not automatically roll back already completed books or file writes.
  • On server restart, any task left IN_PROGRESS is marked CANCELLED with a restart-interruption message. General Task Manager jobs do not resume from their previous checkpoint.
  • After cancellation or restart, inspect the run message and resulting library state before starting a new run. Re-running may revisit work that already completed.

Related Procedures

  • Configure tab visibility and permissions in User Accounts and Permissions.
  • Understand the Tasks parent tab among all settings in Application Settings.
  • Review the BookDrop staging/finalize workflow in BookDrop.
  • Monitor AI Panel Detection or AI Search scans using AI Panel Detection and the AI section of Application Settings.
  • Back up before risky maintenance using Backup and Restore, and inspect administrative history in Audit Logs.
Be Careful:
  • Reconcile Library on a very large library can take a long time and use significant resources.
  • Reconcile Library may remove missing-file entries and purge disallowed formats; use Scan for New Files when you only want to import newly added content.
  • Provider metadata fetches make network calls. ComicVine can visibly pause until its cooldown expires and retry; Hardcover increases delay after throttling; Google Books can report rate limiting without ComicVine’s pause/resume behavior. See Metadata Provider Limits.
  • Notifications are not history: the bell’s Notifications tab is a dismissible WARN/ERROR inbox. Recent runs on each task card is the run history and remains the place to inspect successes, cancellations, item counts, and detailed messages.
